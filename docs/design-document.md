# Design Document

## Project Description

This project is a personal homepage for Ran Cao. It uses vanilla HTML5, CSS3, and ES6 JavaScript modules. The website includes a homepage, an about page, and an AI generated page.

## User Personas

### Persona 1: Recruiter

A recruiter wants to quickly understand my technical skills, projects, and contact information.

### Persona 2: Instructor

An instructor wants to check whether the project follows the assignment requirements, including ES6 modules, multiple pages, organized folders, and valid HTML.

### Persona 3: Classmate

A classmate wants to see the design and understand what kind of projects I am interested in.

## User Stories

- As a recruiter, I want to see a clear homepage so that I can understand Ran's background quickly.
- As an instructor, I want to see semantic HTML and organized files so that I can grade the project easily.
- As a classmate, I want to view the projects section so that I can learn from Ran's project ideas.
